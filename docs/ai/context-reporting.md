# 取得文脈の扱い

## 対象

codebase-retrieval やその他の MCP ツールで、対象そのものに加えて周辺の実装、関連ファイル、類似パターン、不整合の候補が取得できた場合に適用する。

## 回答方針

- まず直接の質問に答える。
- その後に、取得文脈から分かった隣接情報を短く整理する。
- 明示された対象の外にある情報でも、関連性があるものは黙って捨てず、二次情報として圧縮して残す。
- 隣接実装、横断的な影響、重複パターン、関連する実装差、不整合は、必要に応じて「周辺で分かったこと」などの節に分ける。
- 確認済みの根拠と、根拠からの推論を明確に分ける。
- 無関係な推測はしない。
- 情報量が多い場合は、すべてを列挙せず、判断に効くものを優先して要約する。

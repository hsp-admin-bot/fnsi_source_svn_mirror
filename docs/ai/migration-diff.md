# マイグレーション比較ルール

## 前提

本プロジェクトは常に DELETE INSERT をしているため、GII では Diff を取ることができない。

そのため、マイグレーションの比較は単純な行差分ではなく、INSERT 対象主キーごとに、過去の直近 INSERT ブロックをたどって比較する。

## 比較手順

1. まず、今回のマイグレーションファイルを確認する。
2. 次に、INSERT 指定している主キー A を確認する。
3. 同じマイグレーションフォルダから、同じ主キー A を INSERT しているマイグレーションファイルのうち、今回のマイグレーションより前で最も直近のファイルを探す。
4. そのファイルで、同じ主キー A を INSERT しているブロックを確認する。
5. そのブロックと、今回のマイグレーションファイルで主キー A を INSERT しているブロックを比較する。
6. これを、今回のマイグレーションで INSERT している主キーすべてに対して行う。

## AI への期待動作

マイグレーション確認時は、単純なファイル Diff だけで結論を出さないこと。

必ず INSERT 対象主キーを起点に、過去の直近 INSERT 内容を追跡して差分を説明すること。

可能であれば、主キーごとに以下を整理すること。

- 今回 INSERT されたキー
- 直近の過去マイグレーションファイル名
- 過去 INSERT ブロックの内容
- 今回 INSERT ブロックの内容
- 実質的な変更点

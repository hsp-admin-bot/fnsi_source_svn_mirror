# 共通前提

## 最初に確認すること

- このプロジェクトでは、AI はまずリポジトリ構造と参照先の違いを理解したうえで調査する。
- 開発用 Git 管理ディレクトリと、比較元として参照する SVN 管理ディレクトリが存在することを前提にする。
- 詳細なディレクトリ構造や比較先は `docs/ai/repo-structure.md` を参照する。
- codebase-retrieval などの MCP ツールで得た周辺文脈の扱いは `docs/ai/context-reporting.md` に従う。

## 特殊指示

- "ミラーUp"とだけ指示されたら
  - 本スレッドで変更したファイルをGitにあげたいので、fnsi_localのミラーフォルダにファイルを単体配置（ファイルコピー）してください。
  - 対象フォルダがないならディレクトリ作成してください。
  - 当該指示を受けたにも関わらず"C:\FNW\Source"を編集していない場合
    - 「今回はC:\FNW\Sourceを変更しておらず、Upファイルがありません」と返すこと

## 調査時の基本

- codebase-retrieval など、sandbox shell を使わない検索手段を優先する。
- shell_command が必要な場合は、このリポジトリでは 1 コマンドずつ実行する。
- 複数ファイルを読む場合も、同時実行ではなく順次実行する。
- `windows sandbox: spawn setup refresh` が出た場合は、同じコマンドを単発で再実行する。
- 再実行でも失敗する場合のみ、読み取り専用コマンドを require_escalated で実行する。
- require_escalated は一時回避であり、恒久運用にはしない。
- 書き込み・削除・置換・ビルド・外部通信を伴うコマンドは、必要に応じて明示確認を取る。

## 状況別の必読ルール

- Git確認時の安全な読み取り方法は `docs/ai/git-notes.md` を参照する。
- マイグレーション差分確認では通常の単純 Diff ではなく、INSERT 対象主キー単位で直近 INSERT ブロックをたどる。詳細は `docs/ai/migration-diff.md` を参照する。

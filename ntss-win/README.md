# ntss-win
Windowsアプリケーション用のリポジトリです。

# 次世代FN Windowsアプリ ReadMe
次世代FNシステムにおいて、体重計サービス、帳票レイアウトデザイナー、印刷サーバーアプリの3サブシステムがWindowsで動作するアプリです。

# 体重計サービス
次世代FNにおいて、ウェブシステムを中心としたフロントエンド、バックエンドと体重計やカードリーダーなどの体重計周りの機器との接続を担うサブシステムです。
## 体重計サービス 必要システム
* Windows Server 2008 R2以降 または Windows 10以降
* .NET Framework 4.5

## 体重計サービス 初期インストールから初回起動までの手順
1. ビルドにより生成した実行モジュール一式を実行フォルダへコピーします。実行フォルダは任意のフォルダです。
1. 体重計サービスを初めてインストールする場合、コマンドプロンプトで実行フォルダへ移動し、［InstallUtil.exe NKKWeightService.exe］を実行します。サービスプログラムとしてインストールされます。
1. サービス管理ツールに［NKKWeightService」が登録されていることを確認する
1. 実行フォルダにあるNKKWeight.configを実行環境に合わせて更新する
1. サービス管理ツールからNKKWeightServiceを開始する

# 帳票レイアウトデザイナー
次世代FNで出力する帳票をデザインし、デザイン情報のシステムへの登録する担うサブシステムです。
## 帳票レイアウトデザイナー 必要システム
* Windows Server 2008 R2以降 または Windows 10以降
* .NET Framework 4.5
* Microsoft Excel 2016 がPC本体にインストールされていること

## 帳票レイアウトデザイナー 初期インストールから初回起動までの手順
1. ビルドにより生成した実行モジュール一式を実行フォルダへコピーします。実行フォルダは任意のフォルダです。
1. 実行フォルダにあるReportLayoutDesigner.configを実行環境に合わせて更新する。
1. LayoutDesigner.exe を起動する。
1. 初回起動時はIDとパスワードの他に施設ハッシュ値も入力する必要があります。

# 印刷サーバーアプリ
次世代FNにおいて、各サブシステムからの印刷要求を受けて、物理プリンタへの印刷出力を実現するサブシステムです。
## 印刷サーバーアプリ 必要システム
* Windows Server 2008 R2以降 または Windows 10以降
* .NET Framework 4.5
* Acrobat Reader がPC本体にインストールされていること
* いずれかのユーザーでデスクトップにログインしている状態であること。Acrobat Readerがデスクトップ上でしか動作しないため。

## 印刷サーバーアプリ 初期インストールから初回起動までの手順
1. ビルドにより生成した実行モジュール一式を実行フォルダへコピーします。実行フォルダは任意のフォルダです。
1. 体重計サービスを初めてインストールする場合、コマンドプロンプトで実行フォルダへ移動し、［InstallUtil.exe NKKPrintServer.exe］を実行します。サービスプログラムとしてインストールされます。
1. サービス管理ツールに［NKKPrintServer」が登録されていることを確認する
1. 実行フォルダにあるNKKPrint.configを実行環境に合わせて更新する
1. サービス管理ツールからNKKPrintServerを開始する

## 印刷を要求する方法
印刷サーバーアプリのターゲットidに対してWebSocketで印刷要求を送信する。印刷要求は以下のJSON文字列である。{"filename": S3のファイル名,"bucket": バケット名,"printerName": プリンタ名}

例. {"filename": "DE_999000_01_99999999999_20180907.ZIP","bucket": "s3://ntss-s3-root/LOG/999000","printerName": "EPSON LP-S950"}

例. DE_999000_01_99999999999_20180907.ZIP を展開したファイル内のPDFファイルをEPSON LP-S950に印刷する
``` json
{
    "filename": "DE_999000_01_99999999999_20180907.ZIP",
    "bucket": "s3://ntss-s3-root/LOG/999000",
    "printerName": "EPSON LP-S950"
}
```

ターゲットIDは{施設コード6桁}PRINTS{アプリ番号}
例. 999900PRINTS01

# NTSS

 ## サンプル実装の仕様

 対象画面:「施設メンテナンス画面」

 - 画面構成は一覧形式とする。
 - 上記の明細をクリック時に登録画面を表示する

 ### 項目

 表示内容及び入力は下記の通りである

 - 施設コード(10バイト)
   →病医院一意コード
   ※先頭１バイト（１：病医院　２：日機装　３：代理店）←この区分は一旦無視する。
   一意キー。
 - 施設名（128バイト）
   →病医院名称
 - 施設識別コード（20バイト）
   →透析装置に登録されている施設番号（系列施設では一意のコード）
   英数字のみ

 ### その他

 - DB: PostgreSQL

 ### 補足

 透析装置に繋がったエッジ端末からアップロードしてくる情報として、機器の製造番号と施設コードのペアを利用しようとしている。

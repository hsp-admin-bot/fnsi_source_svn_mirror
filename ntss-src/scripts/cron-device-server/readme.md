# cronスケジュールの設定

## 設定方法
1. EC2上に設定ファイル`cron-script.conf`をコピーします。
2. `cron-script.conf`と同じフォルダで次のコマンドを入力し、設定をインポートします。

```
> sudo crontab cron-script.conf
```

 3. 次のコマンドを入力して、設定内容(`cron-script.conf`内の記述)が表示されれば設定は成功です。

```
> sudo crontab -l
```
## 注意事項

- 設定ファイルによるcron処理登録は1ファイルぶんしか行えないため、cron処理を追加する場合は`cron-script.conf`に追記するかたちで設定する。別のファイルをインポートすると、そのファイルの内容で設定が上書きされる。
- `sudo`をつけないでコマンド実行してもエラーにはならないが、スクリプトが`root`権限で実行されなくなる。

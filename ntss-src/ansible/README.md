# デプロイ手順

Ansibleを利用して`ntss-m-notice`をEC2インスタンスにデプロイする手順を示します。

## セットアップ

1. ローカルマシンにAnsibleをインストールする。
 - Windowsの場合は https://qiita.com/komattaka/items/042537c87bb5bef0cfae を参照。
2. `ansible`フォルダを`ntss`フォルダと同じパス階層に配置する。
3. EC2インスタンスにSSH接続するための証明書pファイル(\*.pem)を`~/.ssh`ディレクトリに配置する。

## デプロイ

1. デプロイ対象のwarファイルをビルドする。
2. Ansibleでデプロイを実行する。

## ビルド

```sh
$ ./gradlew build
```

## デプロイの実行

```sh
$ ansible-playbook -i ansible/staging ansible/playbook.yml
```

## データセット取得APIについて

### 概要
`sys_data_set`で定義されているデータセットからデータを取得するAPIについて記載します。

### ビルドおよび実行方法
データセット取得APIは、`ntss-api`プロジェクトに分離されており、ビルドすると`ntss-api.jar`という実行可能JARファイルが生成されます。  
（ファイル名にはバージョン番号などが付く場合があります）

以下のコマンドで実行できます。
プロファイルは環境に合わせて指定してください。
```sh
java -jar ntss-api.jar --spring.profiles.active=???
```

### 呼び出し方法
以下のURLに`GET`リクエストを投げてください。
```
http://localhost:8091/ntss-api/api/data-set
```
※`localhost:8091` は環境によって変わります。呼び出し側の`yml`ファイルなどで指定できるようにしてください。

リクエストボディは以下のような形式のJSONを指定してください。
```json
{
  "sqlCode": 2,   // SQLコード（sys_data_set.sql_cdに該当する値）
  "dataKey": {    // データキー（各データセットで必要とするキーを指定）
    "ordNo": 7
  }
}
```

#### 正常終了した場合
ステータスコード`200`が返ります。   
レスポンスボディにデータ取得結果が配列で返されます。該当するデータが存在しない場合は空の配列が返る場合もあります。
```json
[
  {
    "ord_no": 7,
    "pat_id": 6,
    "fn_pat_id": "00006",
    "treat_date": "20190403",
    "treat_week": 3,
    "facility_cd": "009999",
    "facility_name": "テスト施設名",
    "ind_va_cd": null,
    "ind_treatment_cd": null,
    ...
  }
]
```

#### 異常終了した場合
パラメータ指定が不正な場合は、ステータスコード`400`が返ります。  
レスポンスボディにはエラーメッセージが格納されます。

その他のエラーの場合、ステータスコード`500`が返ります。（`sys_date_set`に登録されているSQLの文法エラーなど）  
レスポンスボディにはエラーメッセージが格納されます。

### カスタマイズ
現在、ポート番号は暫定的に`8091`になっていますが、これを変更したい場合は  
`ntss-api/src/main/resources/application.yml`の以下の行を修正してください。
```yml
server.port: 8091
```

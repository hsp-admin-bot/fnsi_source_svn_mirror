## 画面印刷の対応について

### 概要
ユーザーメニューの`画面印刷`で現在表示中の画面を印刷する際の対応方法について記載します。

#### 実装方法
- 印刷用のCSS(`ntss_print.css`)を用意し、そこに印刷時のみ有効となるスタイルシートを書くことでレイアウト調整などを行っています。
  - `ntss-admin-web/src/main/frontend/public/css/ntss_print.css`
- フッタメニューの非表示など、全画面に対して反映させるスタイルは`ntss_print.css`に記載してください。
- 印刷用CSSでは以下のような対応をしています。
  - スクロールバーが表示されている領域は一度に印刷できるように展開
  - フッタメニュー、コマンドボタン(`確定` `キャンセル`等)の非表示
  - 遠隔監視など画面分割がある画面は、一番右に表示されている画面のみを表示
  - 一覧系の画面で、行ヘッダの`sticky`属性を外す(改ページ時に毎回表示されてしまうため)

#### 画面個別対応の方法
- 画面固有のボタンを非表示するなど、印刷用CSSでは書けないスタイルがある場合は、各vueファイルのスタイルシートで以下のように指定してください。
  ```css
  @media print {
    .machine-record-detail-message {
      height: unset;
    }
  }
  ```
